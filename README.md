# java-lotto-precourse

## 기능 목록

1. 로또 구매 및 발행 
    - 구입 금액 입력 및 검증 
      - 사용자로부터 로또 구입 금액을 입력받는다. 
      - 입력 값이 숫자인지, 1000원 단위로 나누어 떨어지는지 검증한다. (예외 발생 시 IllegalArgumentException)

   - 로또 발행 수량 계산
       - 구입 금액을 기준으로 발행할 로또 수량을 계산한다.

   - 로또 번호 생성 및 정렬 
      - 계산된 수량만큼 로또를 발행한다.
      - 로또 번호는 1부터 45 사이의 중복되지 않는 6개 숫자를 무작위로 생성한다. 
      - 발행된 각 로또 번호를 오름차순으로 정렬한다.
   - 구매 결과 출력 
     - 총 구매 수량 및 발행된 로또 번호 리스트를 출력 요구 사항 형식에 맞게 출력한다.

2. 당첨 번호 및 보너스 번호 입력 
   - 당첨 번호 입력 및 검증 
     - 사용자로부터 쉼표(,)로 구분된 당첨 번호 6개를 입력받는다. 
     - 번호가 6개인지, 1부터 45 사이의 숫자인지, 중복이 없는지 검증한다. (예외 발생 시 IllegalArgumentException)

   - 보너스 번호 입력 및 검증 
     - 사용자로부터 보너스 번호 1개를 입력받는다. 
     - 번호가 1부터 45 사이의 숫자인지 검증한다. (예외 발생 시 IllegalArgumentException)
     - 보너스 번호가 당첨 번호 6개와 중복되지 않는지 검증한다. (예외 발생 시 IllegalArgumentException)

3. 당첨 결과 처리 및 출력 
   - 당첨 등수 판별 및 통계 
     - 구매한 모든 로또와 당첨 번호를 비교하여 일치하는 번호 개수 및 보너스 번호 일치 여부를 확인한다. 
     - 당첨 기준(Rank, Enum 적용)에 따라 등수별 당첨 횟수를 집계한다.

   - 당첨 통계 출력 
     - 당첨 통계 및 구분선(---)을 출력한다. 
     - 3등부터 1등까지의 당첨 기준, 상금, 횟수를 요구 사항의 출력 형식(순서 및 포맷)에 맞게 출력한다.

   - 수익률 계산 및 출력 
     - 총 당첨 금액과 로또 구입 금액을 기반으로 총 수익률을 계산한다. 
     - 수익률을 소수점 둘째 자리에서 반올림하여 첫째 자리까지 표시하고 출력한다.

4. 예외 처리 및 재입력 
   - 예외 타입 지정
     - 사용자의 잘못된 입력 값에 대해서는 반드시 IllegalArgumentException을 발생시킨다.
   - 에러 메시지 형식 
     - 발생한 에러 메시지는 "[ERROR]"로 시작하게 출력한다.
   - 재입력 처리 
     - 예외 발생 시 해당 부분부터 입력을 다시 받는다.
